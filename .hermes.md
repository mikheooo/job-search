# Job Search Monitor

Автоматизированный пайплайн поиска удалённой работы для Михаила: сбор вакансий, матчинг, digest в @remotejobd, отклики.

## Ключевые факты
- Canonical DB: `state.db` (SQLite WAL). Dry-run: env `JOB_SEARCH_DRY_RUN` блокирует записи в БД.
- Активные источники: himalayas, weworkremotely, remoteok, habrcareer, hh. Полная карта — `PROJECT_STATE.md` (читать первым).
- Digest: только genuine-вакансии (dryrun/test/mock/fake запрещены), dedup, max 2/компания, 4/role family.
- Cover letter: команда «откликнись на №N» из Telegram.
- Dashboard: `start_dashboard.bat` (порт 8050, парсит BACKLOG.md через generate_tasks_dashboard.py).

## Правила
- Миграции БД: idempotent (IF NOT EXISTS), транзакционные, откат при ошибке.
- Human-in-the-loop для сложных коммуникаций (отклики, зарплаты) — через Telegram.
- Тесты: pytest в `tests/`, запускать перед "done". Никаких выдуманных результатов.
