# Diagnostic Probes & Mutation Testing Harnesses (tools/probes/)

В данной директории собраны исследовательские зонды (probes) и скрипты мутационного тестирования (mutation harnesses), использовавшиеся в процессе аудита исключений (BLE001), проверки антидетект-свойств браузера и валидации fail-closed инвариантов.

## Назначение

- **Зонды (`*_probe.py`)**: Автономные эмпирические измерения поведения системы в граничных условиях (падение базы, симуляция тайм-аутов CDP, проверка валидации анкет, измерение задержек и заголовков).
- **Мутаторы (`*_mutation.py`)**: Скрипты, временно вносящие точечные программные мутации (мутационное тестирование) для подтверждения, что тестовые гейты и предохранители действительно падают (non-vacuous safety verification).

## Безопасность

- Ни один скрипт из этой директории не импортируется и не запускается в боевом продакшн-раннере (`ai_assistant.runner`).
- Все сетевые вызовы в зондах выполняются строго на локальные loopback-порты или через моки.
- Запуск:
  ```bash
  python tools/probes/<probe_name>.py
  ```
