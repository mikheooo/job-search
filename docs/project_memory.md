## Инварианты честности

Самые дорогие — нарушение делает отчёт лживым, а не просто неточным:

- **`GeoBand`** считается **один раз** в `classify_geo_band`; **B ⇒ UNKNOWN, C ⇒ INELIGIBLE**;
  **ограничение работодателя > ярлык площадки**; **remote-confirmed ≠ Таиланд ⇒ полоса B**.
- **Предохранитель — на ПУТИ ОТПРАВКИ**, не на пути подготовки; `eligible` — только про
  географию; HTTP `403` = «неизвестно», не «запрещено».
- **`USER_DECISION_REQUIRED` ≠ разрешение**: `auto_send_permitted` — только при
  `verdict == CLEAR`; `archived`/`employer` в preflight — **отчёт**, не гейт.
- **Жизненный цикл — ОДНА карта** (`application_tracking._ALLOWED`); тождественный переход —
  no-op **без строки истории**; уборка из очереди — только `transition_application(…, WITHDRAWN)`.
- **`application_submissions.status`** — исход **одной** попытки, не место в цикле ⇒
  расхождение с трекингом **задумано**; запись отправки **не переписывать** ради зелёного аудита.
- **KB/мастер:** `build_master_resume(kb)` → 68 строк; каждый claim — либо rendered, либо в
  `exclusions()`, либо `subsumed()` (122 = 113 + 5 + 4); новый текст — только через
  `PROPOSALS`; класс A — только через `duty`.
- **«Неизвестно» — не «ниже минимума»** (T7.27): зарплата без суммы, курсы валют, базис
  gross/net — всё это `USER_DECISION_REQUIRED`, и **молча не конвертируется**.
