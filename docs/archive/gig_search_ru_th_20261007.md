## Условия доступа и оплаты

Kwork: публичные задания читаются без входа; на карточках есть «Предложить услугу». Авторизация/профиль, доступность коннектов и вывод без карты **UNKNOWN для аккаунта**. Исторические инструкции о кошельках не являются доказательством текущей доступности. Не покупать коннекты и не менять реквизиты в рамках этой проверки.

FL.ru: кнопка отклика доступна, но страница показывает вход/регистрацию. [Правила в FAQ ленты](https://www.fl.ru/projects/) различают бесплатные заказы «для всех» и платный пакет для остальных. Для двух кандидатов бесплатность не подтверждена. На страницах также описана верификация данных физлиц/юрлиц разных стран; прохождение для аккаунта не проверено.

Fastwork: канал заблокирован опубликованными условиями регистрации для не-тайских граждан. Нельзя использовать чужую личность, аккаунт или вывод клиента с площадки, чтобы обходить это условие.
