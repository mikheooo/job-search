# Реестр принятых рисков безопасности (Accepted Security Risks)
Дата утверждения: 2026-11-11
Ветка: `audit/2026-11-11`

Политика безопасности репозитория запрещает использование allowlist по значению секрета (`Secret / Match`) или подавление сканирования каталогов целиком. Настоящий документ фиксирует исторические и синтетические артефакты, выявленные строгим аудитом Gitleaks (`docs/audit/gitleaks-strict.toml` с `[extend] useDefault = true`), классифицирует их статус, фиксирует обоснование и устанавливает сроки окончательного устранения.

- **Количество вхождений в истории:** 108
- **Затронутые коммиты:** `27b3dc98` .. `153956c4` (исторические коммиты до форка и рефакторинга)
- **Затронутые пути в истории:**
  - `ai_assistant/hh_autopilot.py`
  - `ai_assistant/hh_chat_monitor.py`
  - `ai_assistant/telegram_control_bot.py`
  - `ai_assistant/followup_manager.py`
  - `ai_assistant/telegram_auto_apply.py`
  - `scripts/run_telegram_outreach.py`
  - `scripts/run_multi_source_discovery.py`
- **Причина:** Токен старого бота Hermes (`8217526633:AA...`) был зафиксирован в исходных файлах до внедрения `get_secret()` и pre-commit хуков.
- **Статус риска:** **КУПИРОВАН (MINT-DEAD)**.
  - Токен проверен запросом `https://api.telegram.org/bot<TOKEN>/getMe` — ответ `401 Unauthorized` (`{"ok":false,"error_code":401,"description":"Unauthorized"}`). Токен физически отозван на серверах Telegram и не предоставляет доступа.

  - Установлен pre-commit хук Gitleaks 8.30, блокирующий попадание секретов в новые коммиты.
- **Срок окончательного устранения (Rewrite Git History):** Плановое регламентное окно очистки истории Git (`git filter-repo`) после завершения и слияния ветки аудита (Q1 2027) по прямому согласованию с владельцем репозитория.

## 2. Синтетические ключи API в тестовых фикстурах (130 вхождений в тестах)
- **Категория / Правило:** `gcp-api-key` (паттерн `AIzaSy...`)
- **Количество вхождений в кодовой базе:** 130
- **Затронутые файлы:**

  - `tests/test_stage59_autonomous_reply_telegram_audit.py`
  - `tests/test_stage63_telegram_cleanup_and_deeplink.py`
  - `tests/test_stage65_telegram_single_gateway.py`
  - `tests/test_stage66_live_chat_and_clean_contract.py`
- **Причина:** Синтетические тестовые строки, имитирующие ключи Google Cloud / Firebase для юнит-тестирования валидации конфигурации и мокирования ответов в изолированной тестовой среде.
- **Статус риска:** **БЕЗОПАСЕН (SYNTHETIC FIXTURE)**.
  - Строки не являются реальными GCP-ключами, сгенерированы искусственно для тестов.
  - Сокетный guard (`conftest.py:global_test_isolation`) физически блокирует сетевой трафик во время тестов, делая использование любых ключей невозможным.
- **Срок окончательного устранения:** Замена фикстур на несовпадающие с регулярными выражениями GCP строки (`test-mock-key-...`) в рамках планового рефакторинга тестов Telegram-шлюза (до 2027-02-01).
