# T7.9 — прямые каналы найма по трём вакансиям

**Ничего не отправлено. Ничего не изменено.** Работа только в режиме чтения: ни `FULL`, ни
автоответов, ни сообщений, ни приглашений в контакты, ни откликов. Резюме, KB, профиль и
биография не тронуты. Записи Qulix — очередь, tracking, отзыв — не тронуты, `excluded_roles`
не менялся.

---

## 1. Как это проверялось и чего проверить не удалось

**Источники, которые отдали данные:** страницы вакансий и работодателей hh.ru, официальные сайты
компаний, Хабр Карьера, профиль на Хабре, budu.jobs, dreamjob.ru, отзывы сотрудников на hh.

**Источники, которые не отдали данные (и почему это важно):**

| источник | результат | следствие |
|---|---|---|
| `WebFetch` по hh.ru | отдаёт «VPN мешает работе сайта» | все страницы hh читались через `curl` |
| `api.hh.ru/vacancies/<id>` | `403 {"errors":[{"type":"forbidden"}]}` | машинный статус вакансии через API недоступен без токена |
| LinkedIn | ни одной страницы нужной компании (см. §3.4) | LinkedIn как канал исключён |

**Важно про «Откликнуться».** Признаки вроде «Вакансия в архиве» и «Вакансия закрыта» на
страницах hh — это **строки локализации** (`applicant.negotiations.vacancyArchived`,
`negotiations.states.discardVacancyClosed`), а не состояние вакансии: они присутствуют на всех
страницах с одинаковым счётчиком. Единственный надёжный признак живой вакансии — блок
`application/ld+json` типа `JobPosting` с `validThrough` в будущем. Именно им и пользуемся в §2.

**Что считалось «прямым каналом».** Только то, у чего есть ссылка-источник и объяснимая связь
с наймом. Публично опубликованное имя руководителя само по себе каналом найма не является и
ниже помечено отдельно.

### 2.1 Поправка к T7.8: hh **заявляет** географию, а не молчит

В T7.8 было записано «вакансии не заявляют географию (полоса B — возможность работы из
Таиланда не установлена)». Это было верно для сохранённых описаний T7.6, но **неверно для
разметки hh**: у всех трёх вакансий в `JobPosting` стоит одно и то же поле

```json
"applicantLocationRequirements": { "@type": "Country", "name": "Россия" }
```

То есть hh формально объявляет требование «соискатель находится в России». Это **не разрешение**
и **не запрет** — это машинное поле, одинаковое у всех трёх, и оно вполне может быть значением по
умолчанию для региона вакансии, а не отдельным заявлением работодателя. Но читать его как
«география не определена» уже нельзя: полоса остаётся **B**, и вопрос про Таиланд обязателен —
просто теперь он задаётся на фоне явного поля, а не на фоне пустоты.

Ещё из разметки: `jobLocation` — Москва (Академия Йоги), Новосибирск (ОПОРА), Екатеринбург
(EvaTeam); `hiringOrganization.name` — «Академия Йоги», «Юридическая Компания Опора», «EvaTeam».

отклик); не перечисляют неподтверждённые навыки; не заявляют опыт, которого нет в подтверждённых
фактах; не называют формат оформления обязательным условием; не упоминают Таиланд как уже
согласованное.
